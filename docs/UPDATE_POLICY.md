# Política de atualização

1. API e desktop usam versões compatíveis verificadas pelo endpoint `/api/v1/meta/compatibility`.
2. Artefatos Tauri devem ser assinados antes de qualquer distribuição.
3. O canal estável deve ser separado de desenvolvimento/homologação.
4. Atualização automática permanece desativada até o pipeline de assinatura e rollback ser homologado.
5. Nenhum domínio, conta, certificado ou credencial real é criado por este projeto.
