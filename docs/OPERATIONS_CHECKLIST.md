# Checklist operacional

- [ ] Docker Desktop com Client e Server ativos.
- [ ] PostgreSQL acessível somente pela rede autorizada.
- [ ] API `/health` respondendo.
- [ ] Compatibility endpoint respondendo.
- [ ] Backup recente verificado.
- [ ] Restore simulado sem erros.
- [ ] Storage com espaço e permissões corretas.
- [ ] Logs sem senhas, tokens ou payloads sensíveis.
- [ ] Auditoria disponível para responsáveis autorizados.
- [ ] Cloudflare Tunnel, quando aprovado, sem porta pública.
- [ ] Desktop assinado e compatível.
